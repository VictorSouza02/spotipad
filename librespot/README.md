# librespot (trimmed for Spotipad)

Crates from [librespot](https://github.com/librespot-org/librespot) 0.6.0 (MIT, see `LICENSE`) modified for
iOS 9 / armv7, plus the `iosglue` crate with the Spotipad daemon. librespot is also the playback engine of
[Spotifast](https://github.com/crmne/spotifast), the project Spotipad is based on.
The changes are described in `../docs/KNOWLEDGE.md`. Build with `../scripts/build.sh`.
